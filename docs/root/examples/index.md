- [Caddy](caddy/) - A reverse proxy whose routes follow labelled instances, with
  the built-in Caddy preset.
- [Prometheus](prometheus/) - Prometheus `file_sd` scrape targets generated from
  labels, written into Prometheus's volume with no format, validate or reload
  step.
